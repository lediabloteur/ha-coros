# Contributing Guidelines

Thank you for your interest in contributing to this project! To protect the stability, security, and integrity of the integration, please follow these guidelines:

## 📜 Code of Conduct & License
- This project is licensed under the **GNU General Public License v3 (GPLv3)**.
- All contributions submitted via Pull Request are considered licensed under GPLv3.

## 🔒 Branch & PR Rules
1. **No direct pushes to `main`**: All changes from external contributors must go through a Pull Request.
2. **Mandatory Code Review**: Every PR must be reviewed and approved by `@lediabloteur` (Code Owner).
3. **Automated CI Validation**: PRs must pass all automated GitHub Actions checks (`hassfest`, `hacs`, Python syntax validation).
4. **Clean Git History**: Avoid force pushes or rebases that disrupt the commit history.
5. **Zero Secrets Policy**: Never commit credentials, tokens, or private endpoints.
